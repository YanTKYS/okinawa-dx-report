# 沖縄県内11市 DX推進体制・DX推進状況 調査

沖縄県内の全11市を対象に、**DX・業務改善を担う人的体制**と**実際のDX推進状況**の関係を検証する調査リポジトリ。

## 検証する仮説

> DX推進部署・業務改善部署など、DXを専門的に推進する組織の人的体制が充実している自治体ほど、DX推進が進んでいるのではないか

**結論ありきではない。** 正の関係・無関係・負の関係のいずれもあり得るものとして検証している。

### 研究設計の原則

- **判定の唯一の正は `data/scoring_rubric.csv`**（凍結・変更なし）。
  Deep Researchの得点候補は配点超過を含むため一切採用していない。
- **被説明変数を2層に分けている。** 主分析は**実装成果スコア**
  （II 行政手続DX ＋ III 内部業務DX ＋ IV-2 BPR実績 ＋ VI 住民サービス／60点）。
  総合100点スコアには「全庁的推進本部」「BPR専管組織」「外部専門人材」「デジタル人材の採用・配置」など
  **説明変数と構成概念が重複する項目**が含まれ、人員数と相関させると採点設計に由来する相関が生じうるため、
  **総合DXスコア**として感度分析に限定する。ルーブリックは変更していない。
- **補集合からの否定推定は行わない。** 「取組ありに挙がっていないから0点」という導出（旧・導出規則R3）は
  廃止した。確認済み0点は、当該自治体を**名指しで**「無い／未実施」と報告している5件のみ。
- **95%信頼区間を常時併記する**（Fisher z 変換。Pearson は `SE=1/√(n−3)`、
  Spearman は Bonett–Wright (2000) の `SE=√((1+ρ²/2)/(n−3))`）。
  区間が0をまたぐ場合、関係の符号すら確定していない。
- **n<6 は「主分析」と呼ばず「探索的」と表示する**（methodology §9.2.1）。

> 未確認118件を「取り組んでいない」と読んではならない。根拠を確認できていないという意味である。

## データ取り扱いの原則

- **`不明`・`未評価` を 0 として計算しない。** 欠損は集計・相関から除外し、除外数を必ず表示する
- **推測値で補完しない。** 総務省値が取得できない3市は欠損のまま
- **「情報が見つからない」を「実施していない」と判定しない。** 未確認フラグで区別する
- 確度A・Bの一次資料根拠がある項目のみ採点する（確度Cはスコアに反映しない）
- 評価基準は2026-09-15に凍結。**結果に合わせて変更しない**

## 使い方（調査を完了させる手順）

1. **総務省個別資料 Excel 1753／1754／1756行を取得する（最優先）。**
   那覇市・宜野湾市・浦添市の広義人員が入れば主分析が直ちに成立する。
   `tools/build_analysis.py` の `DX_INFO_STAFF` に追記する
2. **DX推進度の未確認項目を埋める。** `data/scoring_results.csv` の
   `status` が `未確認` の行について一次資料を確認し、`tools/scoring_facts.py` に
   事実・URL・確度を追記する（点数はルーブリック条件から判定する）
3. **総務省原Excelで `II-3`・`II-4`・`V-2`・`V-3` の自治体別の非選択を直接確認**する
   （R3廃止で未確認へ戻した28レコードを根拠付きで確認済み0点に戻せる）
4. **人口・普通会計職員数を11市同一定義で取得**し `build_analysis.py` の `POPULATION` / `TOTAL_STAFF` に入力
5. `python3 tools/build_analysis.py` を実行して採点集計・派生列・相関分析を再生成
6. `python3 tools/merge_evidence.py` で根拠を `evidence.csv` へ統合（冪等・何度実行しても同じ結果）
7. `python3 tools/test_checks.py` でデータ品質・再計算ロジックを検証
8. ページを再読み込みすると、散布図・相関係数・補正分析が自動的に更新される（HTMLの修正は不要）

**確認できない値は「不明」のままにすること。0 を入れてはならない。**
