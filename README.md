# 沖縄県内11市 DX推進体制・DX推進状況 調査

沖縄県内の全11市を対象に、**DXを専門的に推進する組織の人的体制**と**実際のDX推進状況**の関係を検証するための調査リポジトリ。

## 検証する仮説

> DX推進部署・業務改善部署など、DXを専門的に推進する組織の人的体制が充実している自治体ほど、DX推進が進んでいるのではないか

本調査は**結論ありきではない**。正の相関・無相関・負の相関のいずれもあり得るものとして設計している。

## ⚠️ 本リポジトリの現在のステータス

**調査は「設計・出典特定」まで完了し、「一次資料による数値確定」は未完了である。**

調査を実施した実行環境から、自治体公式サイト・総務省・デジタル庁・沖縄県のドメインへの
ネットワークアクセスが遮断されており、**一次資料（PDF・組織機構図・定員管理公表資料等）を
1件も開くことができなかった**。

このため本リポジトリは現時点で以下を提供する。

| 提供済み | 未完了 |
|---|---|
| 調査設計・評価基準（確定・凍結済み） | DX担当職員数の確定 |
| 評価ルーブリック（100点満点・項目別配点） | DX推進度スコアの採点 |
| 相関分析の実施手順（事前登録） | 相関係数の算出 |
| 11市の組織名称の暫定把握（確度C） | 一次資料による検証 |
| 各市・各項目の一次資料URL対応表 | — |

**数値を推測で埋めることは行っていない。** 未確認の項目はすべて `不明` / `未確認` として記録している。
詳細は [`docs/okinawa-city-dx-report.md`](docs/okinawa-city-dx-report.md) の「12. 調査上の限界」および
[`docs/sources.md`](docs/sources.md) の「アクセス制約ログ」を参照。

## ファイル構成

```
docs/
  okinawa-city-dx-report.md   最終レポート本体（12章構成）
  methodology.md              調査設計・評価基準・相関分析手順（採点前に凍結）
  sources.md                  出典一覧・一次資料URL対応表・アクセス制約ログ
data/
  municipalities.csv          市別データセット（未確定値は「不明」）
  evidence.csv                データ1件ごとの根拠・確度・検証状態
  scoring_rubric.csv          評価ルーブリック（機械可読版）
```

## 使い方（調査を完了させる手順）

1. `data/evidence.csv` の `verification_status` が `未検証` の行を対象に、記載された `source_url` を開く
2. 値を確認して `value` を更新し、`confidence` を A/B/C で付与、`verification_status` を `検証済` に変更
3. `docs/methodology.md` の評価基準に従って採点する（**基準は変更しないこと**）
4. `data/municipalities.csv` を更新し、相関分析を実施する
