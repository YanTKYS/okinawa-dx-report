# 調査方法（methodology）

**確定日：2026年9月15日**
本文書の評価基準は、個別自治体の採点に着手する前に確定させたものである。
採点結果に合わせて基準を変更してはならない。変更する場合は変更履歴を末尾に追記し、
全市を新基準で再採点すること（一部の市だけ再採点してはならない）。

---

## 1. 調査目的と仮説

### 検証仮説（H1）
DXを専門的に推進する組織（DX推進部署・業務改善部署等）の人的体制が充実している自治体ほど、
DX推進が進んでいる。

### 対立仮説
- H0：DX人的体制とDX推進度の間に関係はない
- H2：負の関係がある（例：DXが進んだ結果として担当人員を縮小できる、
  あるいは人員が多い団体ほどレガシー業務の運用負荷が高く新規施策に手が回らない）

**本調査はH1・H0・H2を等しく検証対象とする。**
「人員を増やすべき」という結論に合わせたデータ選択・基準調整は行わない。

### 本調査が目的としないこと
- 自治体間の優劣ランキングの作成
- 特定自治体の評価・格付け

スコアは**相関分析のための説明変数／被説明変数**としてのみ用いる。

## 2. 調査対象

沖縄県内の全「市」11団体。

那覇市、宜野湾市、石垣市、浦添市、名護市、糸満市、沖縄市、豊見城市、うるま市、宮古島市、南城市

- 町村（11町19村）は対象外。市町村合計41団体のうち市は11団体。
- 調査時点（2026年9月15日）において、市への昇格・市町村合併の予定は確認されていない。
  最後の市制施行は南城市（2006年1月1日、4町村合併）である。
  ※この点は沖縄県公式サイトの市町村一覧で最終確認を要する（確度C・未検証）。

## 3. 調査手順

1. 調査設計・仮説定義
2. **評価基準の確定（凍結）** ← 本文書
3. 情報収集（一次資料の取得）
4. データ整理（`data/evidence.csv` への記録、確度付与）
5. 分析（記述統計 → 相関分析 → 外れ値分析 → 交絡要因検討）
6. レポート作成
7. 出典・データ整合性確認

手順2を手順3より前に置くことが本調査の要である。

---

## 4. 情報源の優先順位

以下の順に優先する。下位の情報源は、上位の情報源が存在しない場合の補完としてのみ用いる。

| 優先 | 情報源 |
|---:|---|
| 1 | 自治体公式サイト |
| 2 | 自治体DX推進計画・情報化計画 |
| 3 | 組織機構図 |
| 4 | 職員配置表・行政機構資料・給与定員管理等の公表資料 |
| 5 | 当初予算・主要事業説明資料 |
| 6 | 議会会議録 |
| 7 | 自治体公式プレスリリース |
| 8 | 総務省・デジタル庁・沖縄県等の公的資料 |
| 9 | 報道記事等 |

### 検索結果の取扱い（重要）
検索エンジンの結果一覧・スニペット・検索結果の自動要約は**根拠として採用しない**。
これらは「原資料の所在を特定する手段」としてのみ用い、値の確定は必ず原資料の確認による。

本調査では実際に、検索結果の自動要約が「令和7年度」を "fiscal year 2026" と
誤変換する事例（正しくは2025年度）が発生している。要約を根拠にしない原則の実効性を示す実例として記録する。

---

## 5. 情報確度の区分

すべてのデータに以下の確度を付与する。

| 確度 | 定義 |
|---|---|
| **A** | 一次資料を直接確認した。原資料のURL・該当箇所を特定できる |
| **B** | 複数の独立した情報から高い確度で確認した。一次資料そのものは未確認 |
| **C** | 間接的情報のみ（検索結果スニペット、第三者サイト、要約等） |
| **不明** | 判断できない |

**分析ではA・Bのデータのみを用いる。** C以下のデータは参考情報として本文に記載するが、
スコア算出・相関分析には投入しない。

---

## 6. 「確認できない」の取扱い（最重要ルール）

**「情報が見つからない」ことと「取り組んでいない」ことを区別する。**

- 情報が確認できない項目は `未確認` フラグを立て、素点は0点とする
- ただし本文・表において「実施していない」とは記載しない
- 各市について `未確認項目数` と `未確認配点合計` を必ず併記する
- 未確認配点が全配点の30%を超える市は、スコアを**参考値**として扱い、
  相関分析の主分析から除外する（感度分析には含める）

### 正規化スコアの併用
未確認項目の多寡による見かけ上の不利を補正するため、以下の2つを併記する。

- **素点（raw score）** ＝ 確認できた得点の合計（0〜100）
- **補正スコア（adjusted score）** ＝ 素点 ÷ 判定可能だった配点合計 × 100

相関分析は**素点・補正スコアの両方**で実施し、結論が両者で一致するか確認する。

## 7. DX推進体制（説明変数）の定義

### 7.1 組織項目（記述用・スコア化しない）

- DX推進担当部署名
- 情報政策担当部署名
- 行政改革・業務改善担当部署名
- DX専任組織の有無
- 組織階層（部／課／室／係／プロジェクトチーム）
- CIO・CDO・CIO補佐官・DXアドバイザー等の有無
- DX専門部署の設置年月（設置からの経過年数）

### 7.2 人員項目（相関分析の説明変数）

人員は**機能別に区分して計上する**。「情報政策課10人」を「DX担当10人」と扱ってはならない。

| 区分 | 内容 |
|---|---|
| ① DX・業務改革 | DX企画、BPR、業務改善、デジタル施策の企画立案 |
| ② 情報システム運用・インフラ | 基幹系・情報系システムの運用保守、ネットワーク、標準化・共通化対応 |
| ③ 情報セキュリティ | セキュリティポリシー、監査、インシデント対応 |
| ④ その他 | 統計、庶務、その他 |

- **区分できない場合は推測せず「確認不能」とする。**
- 兼務者は実人数と兼務の別を記録する（常勤換算は行わない。按分は推測を伴うため）。
- 会計年度任用職員・外部人材（CIO補佐官、DXアドバイザー、委託常駐等）は別カウントとする。

### 7.3 主要説明変数

| 変数 | 定義 |
|---|---|
| `dx_staff` | DX担当職員の絶対数（区分①、兼務含む実人数） |
| `dx_dedicated_staff` | うち専任者数 |
| `dx_staff_per_10000_population` | `dx_staff` ÷ 人口 × 10,000 |
| `dx_staff_per_100_staff` | `dx_staff` ÷ 自治体職員総数 × 100 |
| `external_dx_staff` | 外部デジタル人材数 |

人口・職員総数は出典・基準日を必ず記録する。
人口は住民基本台帳人口または沖縄県推計人口のいずれかに統一し、混在させない。
職員総数は普通会計職員数（総務省定員管理調査ベース）に統一する。

## 8. DX推進度（被説明変数）の評価基準【凍結】

### 設計方針
- 全11市について**比較可能**であり、**公開情報から客観的に確認できる**指標に限定する
- 施策の「件数」で加点しない（件数は規模の代理変数になりやすい）
- 「最新技術を導入しているか」ではなく「定着・全庁展開しているか」を見る
- 各項目は原則として**実施状況の段階評価**とする

### 配点表（合計100点）

#### I. DX推進方針・推進体制（20点）

| No | 項目 | 配点 | 判定方法 |
|---|---|---:|---|
| I-1 | DX推進計画・方針の策定 | 6 | 独立したDX推進計画/方針＝6／情報化計画等の関連計画に包含＝3／確認できず＝0（未確認） |
| I-2 | 計画の現行性 | 4 | 調査時点が計画期間内＝4／期間終了かつ改定公表あり＝2／期間終了で改定未確認＝0 |
| I-3 | 全庁的推進本部の設置 | 5 | 設置要綱等の規程を確認＝5／計画本文等で言及のみ＝2／確認できず＝0（未確認） |
| I-4 | ロードマップ・KPI・進捗公表 | 5 | 数値KPIと進捗実績の両方を公表＝5／KPI設定のみ＝3／ロードマップのみ＝1／確認できず＝0 |

| VI-3 | オープンデータ | 4 | 推奨データセット公開かつ更新継続＝4／ページ設置のみ＝2／確認できず＝0 |
| VI-4 | 公共施設予約等のオンライン化 | 3 | オンライン予約・決済まで＝3／予約のみ＝1.5／確認できず＝0 |

### 採点上の共通ルール
1. 判定は**一次資料**によってのみ行う（§4・§5）
2. 「検討中」「予定」は実施中の**半分**の配点とする
3. 確認できない項目は0点とし、必ず `未確認` フラグを立てる
4. 同一項目の判定基準を市によって変えてはならない
5. 判定に用いた資料のURLを `data/evidence.csv` に必ず記録する

## 9. 相関分析の手順【事前登録】

### 9.1 主分析

以下の3組について相関を算出する。

| # | 説明変数 | 被説明変数 |
|---|---|---|
| 1 | `dx_staff`（絶対数） | DX推進度スコア |
| 2 | `dx_staff_per_10000_population` | DX推進度スコア |
| 3 | `dx_staff_per_100_staff` | DX推進度スコア |

### 9.2 統計量
- **Spearman順位相関係数（ρ）を主指標とする。**
  n=11と小標本であり、正規性を仮定できず、外れ値の影響を受けにくいため。
- Pearson相関係数（r）も併記し、両者の乖離を確認する（乖離は外れ値の存在を示唆する）。
- 95%信頼区間を併記する。

### 9.3 有意性の判断と検出力の限界
- n=11におけるSpearman ρ の有意水準5%（両側）の臨界値は概ね **ρ ≈ 0.62**
- すなわち **|ρ| < 0.62 は統計的に有意でない**
- n=11では中程度の相関（ρ≒0.4）を検出する検出力は概ね0.3未満であり、
  **「有意でない＝関係がない」とは結論できない**
- 逆に有意であっても、**因果関係の証明にはならない**

### 9.4 やってはならないこと
- 相関係数から「人員を増やせばDXが進む」と因果を断定すること
- 有意でない相関を「傾向が見られる」と実質的に有意であるかのように記述すること
- 外れ値を理由なく除外して相関係数を改善すること
  （除外する場合は除外前後の双方を必ず併記する）

### 9.5 外れ値分析（必須）
相関係数の算出とは独立に、以下を個別に検討する。
- 少人数でDX推進度が高い市 → 何が代替しているか（外部委託・首長方針・広域連携・外部人材）
- 人員が多くDX推進度が低い市 → 人員が何に充てられているか（①〜④区分の内訳を再確認）

### 9.6 ペア比較（必須）
統計分析に加え、**人口規模が近い2市の対比**を行う。
相関係数よりも実務的示唆が得られる可能性が高いため、本調査では必須の分析とする。

想定ペア（人口規模順・確度Cの人口概数に基づく暫定案）：
- 沖縄市 ⇔ うるま市（いずれも12〜14万人規模）
- 浦添市 ⇔ 宜野湾市（いずれも10〜11万人規模）
- 石垣市 ⇔ 宮古島市（いずれも5万人規模・離島）
- 糸満市 ⇔ 豊見城市（いずれも6万人規模・本島南部）

## 10. 交絡要因の検討【必須】

相関の解釈にあたり、以下を必ず検討する。

| # | 交絡要因 | 確認方法 |
|---|---|---|
| 1 | 人口規模 | 人口を制御変数とした偏相関、または人口階層別の比較 |
| 2 | 自治体職員総数 | 職員100人あたり指標での再検証 |
| 3 | 財政規模 | 標準財政規模・財政力指数・歳出総額 |
| 4 | 情報政策部署がインフラ運用も担当しているか | 機能区分①②の内訳。②の比率が高いほど①に充てられる実質人員は少ない |
| 5 | 外部委託の程度 | 情報システム関係の委託料（当初予算）。委託が厚いほど内部人員は少なくても推進しうる |
| 6 | 外部デジタル人材 | CIO補佐官等の任用の有無（特別交付税措置の対象） |
| 7 | 首長・経営層のDX方針 | 施政方針演説、公約、デジタルファースト宣言等 |
| 8 | DX専門部署設置からの経過年数 | 設置年月からの経過年数。施策の蓄積は時間の関数でもある |
| 9 | 離島・地理的条件 | 石垣市・宮古島市は本島市部と条件が異なる |
| 10 | 広域連携・県の支援事業 | 沖縄県のDX人材確保育成市町村支援事業等の活用状況 |

**「DX人員」と「DX推進度」だけで説明できない事例を特に重視する。**

## 11. 再現性

- すべての数値は `data/evidence.csv` により根拠資料まで追跡可能とする
- 評価基準は `data/scoring_rubric.csv` に機械可読形式で保持する
- 分析を再実行する場合も、本文書の基準を変更してはならない
